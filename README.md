# FreeToken Radar · 免费 AI Token 实时雷达

一个**纯静态 + 自带爬虫**的免费 AI 额度导航页：玻璃拟态视觉、PC / Android 双端自适应、
数据由爬虫定时抓取并实时同步到页面。

---

## 一、怎么打开

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| **推荐**：本地服务 | 双击 `start.bat` | 自动起 `http://127.0.0.1:8080`，后台每 5 分钟抓一次，页面每 60 秒轮询，**真正实时** |
| 快速预览 | 直接双击 `index.html` | 用 `data/offers.js` 内嵌快照渲染，页面右上角显示「本地快照」 |
| 手动刷新数据 | 双击 `refresh.bat` | 只抓一次，刷新浏览器即可看到最新数据 |

> 需要本机有 Python（3.8+ 即可，**只用标准库**，无需 pip install）。
> 手机访问：让手机和电脑连同一个 Wi-Fi，把 `crawler/serve.py` 里的 `127.0.0.1` 改成 `0.0.0.0`，
> 然后用 `http://电脑IP:8080` 打开。

## 三、实时更新是怎么做的

```
┌──────────────┐   每 5 分钟     ┌────────────────┐   每 60 秒轮询   ┌──────────┐
│ 数据源(3 个) │ ─────────────▶ │ data/offers.json│ ──────────────▶ │  页面    │
└──────────────┘   抓取 + 清洗   └────────────────┘   比对 generated_at└──────────┘
```

1. **抓取**：`fetch_offers.py` 并发（顺序）请求 3 个源，带 UA、gzip、超时重试与镜像回退。
2. **清洗**：三套抽取器分别处理 Markdown 表格、HTML 标题+段落、JSON 模型目录，
   再经过噪声过滤（字段行、目录行、营销话术）与字段前缀剥离。
3. **合并**：以标题指纹去重，实时条目排在人工核验条目前面，按日期倒序。
4. **输出**：同时写 `offers.json`（fetch 用）和 `offers.js`（file:// 兜底）。
5. **推送**：页面每 60 秒 `fetch` 一次并比对 `meta.generated_at`，变了才重绘并弹提示；
   标签页隐藏时暂停轮询，切回来立即补一次。

抓不到数据时（断网 / 被墙 / 源站改版），页面自动回退到内嵌快照，功能不受影响，
状态胶囊会变成橙色的「本地快照」。

## 四、怎么改内容

### 加一个平台 / 改额度

编辑 `data/seed.json` 的 `offers` 数组，字段说明：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识 |
| `name` / `brand` / `mono` | 卡片标题 / 品牌名 / 图标里的字母 |
| `c1` / `c2` | 品牌渐变色（用于图标底色和卡片光晕） |
| `region` | `国内` / `海外` / `本地` |
| `category` | `official` 长期免费 / `newbie` 新人赠送 / `limited` 限时活动 / `oss` 开源自部署 |
| `quota` / `quotaNum` | 额度标题 / 大号额度（`1440 次/天` 这种会被自动拆成数字+单位） |
| `detail` | 说明，卡片里最多显示 3 行 |
| `tags` | 标签数组 |
| `url` / `docs` | 领取入口 / 官方说明 |
| `deadline` | `YYYY-MM-DD`，有值会自动算「剩 N 天」倒计时 |
| `verified` | 核验日期 |
| `weight` | 推荐权重，越大越靠前 |

改完跑一次 `refresh.bat`（或 `python crawler/fetch_offers.py`）重新生成产物。

### 加一个数据源

编辑 `crawler/sources.json`：

```json
{
  "name": "显示名",
  "url": "https://...",
  "fallbacks": ["https://镜像地址"],
  "kind": "html",          // html | markdown | json | openrouter
  "limit": 5               // 最多取几条
}
```

`kind` 决定用哪个抽取器；`keywords` 是入选关键词，`exclude` 是排除词。

## 六、设计说明

- **玻璃拟态**：`backdrop-filter: blur(22px) saturate(170%)` + 1px 高光描边 + 内阴影，
  叠在四团缓慢漂移的极光色块上；再铺一层 SVG 噪点和网格线增加质感。
- **双主题**：默认深色极光，右上角可切浅色「磨砂白」，选择写入 `localStorage`。
- **响应式**：≥1080px 双栏 Hero；≤860px 折叠导航；≤640px 单列卡片、筛选条横向滚动。
- **交互**：卡片光斑跟随鼠标、滚动进场、截止日倒计时、`/` 聚焦搜索、
  一键复制示例命令、数据更新 Toast、回到顶部。
- **性能与可访问性**：零框架、零外部依赖（字体走系统栈，图标内联 SVG）；
  支持 `prefers-reduced-motion`、`:focus-visible`、`aria-*` 与 `noscript` 提示。

## 七、部署到线上

页面是纯静态的，把整个目录丢到 GitHub Pages / Netlify / Vercel 即可；
实时数据用系统计划任务定时跑 `fetch_offers.py` 并提交 `data/` 变更：

```bash
# Linux/macOS crontab：每 5 分钟抓一次
*/5 * * * * cd /path/FreeTokenHub && python3 crawler/fetch_offers.py
```
